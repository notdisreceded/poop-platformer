*This repository contains the source code and assets of the game Poop Platformer by Disreceded
Poop Platformer is created in the Godot engine*

# Controls
W / Spacebar / Up Arrow - Jump

A - Move Left

D - Move Right

# Mechanics
You can't poop forever, so managing your poop is important.
Jumping depletes your poop meter, and if your poop meter gets too low, you hop instead, and you
do not regenerate poop for a while.
